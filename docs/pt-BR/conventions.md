# Convenções

**Português** · [English](../en-US/conventions.md) · [Deutsch](../de-DE/conventions.md)

- Preserve nomes qualificados Mendix nas referências.
- Use `snake_case` nos arquivos Ruby sem mudar a identidade do artefato.
- Faça preview de rename, move, remove e migração antes do apply.
- Declare papéis de páginas e flows em projetos protegidos.
- Dê uma home padrão a cada perfil de navegação.
- Mapeie homes por papel a user roles com acesso ao alvo.
- Prefira tokens a estilos literais locais.
- Writers tipados alteram apenas campos explicitamente declarados.
- Themes, widgets, resources e fontes Java fazem parte do round-trip.
- Rode RSpec, branch report e RuboCop antes de enviar mudanças.

A validação exata do Mendix 5 em Windows permanece documentada como limitação
legada, mas não é um gate atual de entrega.
